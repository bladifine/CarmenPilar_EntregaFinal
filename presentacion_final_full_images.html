Introducción

Origen

"Este proyecto nace de ese silencio incómodo entre la pregunta ciudadana recurrente y la respuesta manual rezagada..."

La Realidad Cotidiana

Múltiples ciudadanos acuden semanalmente con interrogantes idénticas: ¿Cuándo empieza el curso?, ¿Cuáles son los requisitos? El personal administrativo repite incansablemente las mismas respuestas, generando fatiga operativa.

El Enfoque Humano

BotEduCarmen no busca reemplazar al ser humano, sino devolverle tiempo valioso para ejecutar labores de orientación y acompañamiento pedagógico directo.

Diagnóstico del Problema

Problemas Críticos Identificados

  • Falta de información sistematizada: Inexistencia de repositorios y bases de datos centralizadas.
  • Comunicación ineficaz: Dependencia estricta de carteleras físicas tradicionales.
  • Paradigma Socio-Crítico: Se empodera a los actores comunitarios para co-construir soluciones a su realidad mediante la informática.

Justificación

Pilar Humano y Social

Libera al personal de tareas mecánicas y democratiza el acceso libre a la información sin requerir traslados costosos.

Pilar Técnico

El uso de la nube con Firebase reduce costes de infraestructura local y asegura alta disponibilidad 24/7 sin caídas por cortes eléctricos locales.

Marco Teórico (Tecnología Cloud)

Bases de Datos NoSQL (Firestore)

Almacenamiento orientado a documentos JSON flexibles. Permite lecturas ultrarrápidas y sincronización en tiempo real para las consultas dinámicas del asistente.

Asistentes Virtuales en la Nube

Herramientas capaces de simular interacción inmediata. Al integrarse con el SDK de Firebase, consultan colecciones instantáneamente.

Arquitectura y Especificaciones

Objetivo: Implementar BotEduCarmen mediante una arquitectura Serverless basada en la plataforma Google Firebase para optimizar la difusión del catálogo.

Entradas

Consultas en lenguaje natural e inscripciones estructuradas de alumnos.

Salidas

Respuestas inmediatas en el chat y reportes en tiempo real desde Firestore.

Script de Conexión e Inicialización (firebase.js)

Código Fuente

Inicialización segura del backend del asistente virtual utilizando el SDK de Firebase:

import { initializeApp } from "firebase/app";
import { getFirestore } from "firebase/firestore";

const firebaseConfig = {
  apiKey: "AIzaSyA1...",
  authDomain: "boteducarmen.firebaseapp.com",
  projectId: "boteducarmen",
  storageBucket: "boteducarmen.appspot.com",
  messagingSenderId: "12345678",
  appId: "1:1234:web:abcd"
};

// Inicializar la aplicación y base de datos Cloud Firestore
const app = initializeApp(firebaseConfig);
export const db = getFirestore(app);

Despliegue en Firebase Hosting

Pasos para Producción Cloud

  1. Instalar herramientas de consola globales:
    npm install -g firebase-tools
  2. Autenticar sesión: firebase login
  3. Vincular el directorio local al proyecto: firebase init
  4. Desplegar el portal y el bot a la nube de manera pública:
    firebase deploy

Recomendaciones para el Bot y Dashboard

Buenas Prácticas

Uso y Mantenimiento de la Plataforma

  • Actualización Continua: Mantener al día la colección cursos en Firestore para evitar que el bot entregue información obsoleta.
  • Revisión de Métricas: Consultar periódicamente los logs en la consola Firebase para identificar dudas no resueltas e incorporar nuevas respuestas.
  • Respaldo Periódico: Exportar periódicamente las colecciones NoSQL de la base de datos como medida preventiva.
